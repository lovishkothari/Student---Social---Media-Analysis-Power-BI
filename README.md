# 📊 Student Social Media Analysis | Power BI

##  Project Overview

This project is an interactive **Power BI dashboard** developed to analyze student social media usage and its relationship with mental health, lifestyle, academic performance, relationships, and social media platforms.

The project uses an Excel dataset as the source data and presents the analysis through interactive Power BI report pages.

---

##  Project Objectives

- Analyze student social media usage patterns
- Understand the relationship between social media and mental health
- Explore lifestyle and sleep-related factors
- Analyze the impact of social media on academic performance
- Examine relationships and conflicts
- Compare different social media platforms
- Explore individual student profiles
- Present insights through interactive Power BI dashboards

---

##  Dashboard Pages

### 1. Executive Overview
Provides a high-level summary of the student social media analysis and key metrics.

### 2. Mental Health & Lifestyle
Analyzes social media usage in relation to mental health and lifestyle factors.

### 3. Academic Impact
Explores the relationship between social media usage and academic performance.

### 4. Relationships and Conflicts
Analyzes how social media usage relates to relationships and conflicts.

### 5. Interactive Story View
Provides an interactive view of the major findings from the analysis.

### 6. Student Profile
Allows analysis of individual student-level information and characteristics.
